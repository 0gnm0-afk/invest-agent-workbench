텔레그램 뉴스 연결

가입한 채널·그룹에서 키워드와 기간으로 뉴스를 찾습니다. 뉴스는 저장하지 않습니다. API ID·Hash와 로그인 세션은 Windows 사용자 계정으로 암호화해 저장하고, 다음 실행부터 자동 연결합니다.

Codex로 가져온 검색 결과는 대화 기록에 남을 수 있습니다. 검색 결과는 기사 후보이므로 원 출처를 확인하세요.

연결 상태 확인 중…

1. API 발급 후 로그인

my.telegram.org → API development tools → 앱 등록 → API ID와 API Hash 발급. 앱 이름은 본인이 알아볼 이름으로 정하세요.

다음 실행에도 API ID·Hash는 재사용합니다. 전화번호·인증 코드·2단계 비밀번호는 저장하지 않고, 인증이 끝난 세션만 암호화 저장합니다.

2. 계정 확인

직접 조회 (선택)

종목분석은 스킬이 MCP로 수행합니다. 아래는 연결 확인을 위한 선택 기능입니다.
