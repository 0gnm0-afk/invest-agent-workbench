# M06 작도와 세션 연결

개정: 2026-11-17 · DESIGN-3-20261117 · **§8 반영 초안·사용자 승인 전** · 상세 설계 / 설계 검토 가능

입력: [3단계 설계 §8](<../3단계 설계.md#8-모듈-문서-열린-질문에-대한-설계-결정-2026-11-17>), [ver3.1](../투자에이전트ver3.1.md), [용어집](../용어집.md). §8이 앞선 계약·순서보다 우선한다. `확정`은 상위 결정, `구현안`은 이 문서의 구현 선택, `결정 필요`는 끝의 열린 질문이다. 파일:줄은 2026-11-17 정적 확인 기준이며 코드 변경·시험 실행은 하지 않았다.

## 앞 절반 — 설명서

### 1. 하는 일

사용자가 그린 선·채널·박스를 저장하고 세션에서 좌표와 짧은 설명으로 읽는다.
저장된 최신 완료 일봉 종가가 선에서 얼마나 떨어져 있는지 보여 준다.
화면에 보이는 과거 구간에는 자동 L1 추세선을 참고선으로 따로 그린다.

### 2. 입력과 출력

종목과 저장된 작도·가격을 받아 **최신 저장 작도**와 **채택 계획이 참조한 당시 작도**를 나누어 보여 준다. 각 그림에는 좌표, 기준일, 선값, 거리, 수정 번호와 작업공간 저장 시각이 붙는다. 채택하지 않은 AI 제안은 제외한다.

자동 L1 추세선은 보이는 구간의 상승·하락을 요약한다. 계산한 구간과 시간틀을 함께 보여 주며 사용자 작도와 섞어 저장하지 않는다. 그림·가격이 없거나 계산할 수 없으면 그 이유를 알린다.

### 3. 저장 위치

사용자 작도와 이력은 기존 `runtime/chart-workspaces.sqlite3`의 작도 테이블에 남긴다. 분석·계획은 M05가 관리한다. 세션 읽기 결과와 자동 L1 추세선은 저장하지 않는다.

### 4. 다른 모듈과의 연결

| 계약 | 연결 (§8 반영) |
|---|---|
| C1 | 작도 쓰기 함수는 M06 소유다. M05의 채택과 M06의 작도 추가를 같은 거래 단위로 묶는 기존 방식은 유지한다. |
| C2 | 가격은 M03의 저장 읽기 함수만 쓴다. `market/history/chart.py`도 M03 소유다. |
| C3 | M09의 `investment_drawings`로 최신·채택 작도를 읽고 자동 L1 추세선은 별도 묶음으로 받는다. |
| C5 | M07은 정확한 채택 작도 수정본과 이전 참조를 보존한다. 자동 L1 선은 감시·알림에 쓰지 않는다. |
| C6·C7 | 세션 도구와 `investment_context` 연결은 M09, HTTP 경로·화면 골격 연결은 M10이 맡는다. |
| C8 | 완료 검사는 M00 실행기와 임시 합성 자료로 한다. 실제 자료 확인은 별도 운영 적용이다. |

### 5. 이번 개편에서 바뀌는 것 / 그대로인 것 / 없어지는 것

- **바뀌는 것:** 저장 내용을 바꾸지 않는 작도 읽기와 화면 구간별 자동 L1 선을 추가한다.
- **그대로인 것:** 사용자 좌표·수정 이력·충돌 방지와 채택 당시 기록을 보존한다.
- **없어지는 것:** 옛 자동 추세선(trendln)은 M01이 종료한다(§8.7). M06은 옛 코드를 옮기지 않고 L1 참고선을 새로 만든다.

### 6. 쓰는 법

대시보드에서 작도를 저장한 뒤 세션에 “이 종목의 작도를 읽어 줘”라고 한다. 최신 그림과 채택 당시 그림의 기준일·수정 번호를 함께 확인한다. 자동선은 화면 이동·확대가 멈추면 보이는 완료봉 구간으로 다시 그린다. 세션에서도 구간을 지정할 수 있고 생략하면 대시보드 기본 구간을 쓴다. 자동선은 매매 신호가 아니다.

### 7. 사용자가 직접 확인하는 방법

5단계 합성 자료 검수에서 선·채널의 좌표와 수정 번호가 화면과 세션에서 같은지 본다. 선을 바꿔도 채택 당시 그림은 그대로인지, 화면을 이동하면 자동선과 계산 구간이 함께 바뀌는지 확인한다. 최신 완료봉까지 보이는 마지막 구간은 “진행 중” 점선이어야 한다. 실제 저장 자료를 쓰는 검수는 뒤의 **운영 적용(Claude, 사용자 승인)**으로 분리한다.

## 뒤 절반 — 작업 지시서

### 1. 범위와 목표

**확정:** 조 3의 M05 다음에 구현한다. M00 실행기, M01 종료 정리, M03의 저장 가격·봉 읽기 함수, M05의 정확한 채택 참조 읽기 함수가 선행한다. 조 3 뒤 M07은 자기 시나리오 감시의 작도 읽기를 이 함수로 바꾸며, M09·M10은 조 4에서 세션·HTTP를 연결한다. M06 조회는 감시 등록·동기화·판정을 호출하지 않는다.

범위는 작도 저장·기하 계산 보존, C3 읽기, 자동 L1 계산과 화면 조각이다. 수집·계좌·주문·가설 자동 판정·실적일 수집은 범위 제외다. 정성 반증 조건은 작도 숫자로 바꾸지 않는다.

**C3 확정(§8.4):**

| 항목 | 구현할 계약 |
|---|---|
| 선택 | (a) 최신 공유 작업공간의 저장 작도, (b) 채택된 계획이 참조한 정확한 revision의 작도. 미채택 AI 제안 제외. 두 묶음은 같아도 출처를 구별한다. |
| 가격 | 저장된 최신 완료 **일봉 종가와 그 날짜**를 비교값으로 쓴다. 실시간 현재가로 표시하지 않는다. |
| 계산 | 저장된 작도 시간틀로 계산하고 없으면 일봉. 거리 = `종가 - 선값`, % = `(종가 - 선값) / 선값 × 100`. 선값 0·가격 없음은 계산 불가로 표시한다. |
| 시각 | 해당 revision의 `updated_at`을 `workspace_saved_at`으로 반환한다. 도형별 수정 시각을 만들어 내지 않는다. |
| 근거 | `stock_key`, 가격 기준·참조, `drawing_id`, 종류·원좌표, `workspace_revision`, 연결된 계획·snapshot 식별자, 계산 시간틀·기준일·제한 이유를 보존한다. 문장은 같은 수치·날짜·revision으로 만든다. |
| 상태 | 그림 없음·가격 없음·과거 참조 없음·자료 오류·계산 불가를 구별한다. 결측을 0이나 정상 빈 목록으로 바꾸지 않는다. |

현재 도형 스키마는 시간틀을 저장하지 않으므로 최신 공유 작도는 일봉 대체 규칙을 적용한다(`store.py:44`·`:230`). 채택 참조에는 `timeframe`이 있으므로 M05가 검증한 값을 쓴다(`collaboration.py:124`·`:129`). 과거 payload를 바꾸거나 저장되지 않은 작성 시간틀을 추측하지 않는다.

**구현안:** `scripts/drawings/interpretation.py`에 읽기 전용 조립 함수를 둔다. M03 가격 reader·M05 채택 reader·M06 workspace reader를 명시적으로 받으며 운영 기본 경로를 숨겨 선택하지 않는다. 기존 `AnalysisService` 초기화·`capture()`·`analysis_read`를 호출하지 않는다. MCP 이름은 이미 `investment_drawings`로 확정됐고 공개 인자·등록은 M09 소유다.

**자동 L1 확정(§8.1):**

1. 입력은 종목, 화면 구간 시작·끝, 시간틀(`1d`·`1w`·`1mo`)이다. M03의 저장 일봉 읽기·집계 결과에서 보이는 완료봉만 사용하고 미래 슬롯은 제외한다. 화면 이동·확대/축소가 멈춘 뒤 짧은 지연으로 한 번 계산한다.
2. 해당 구간 로그 종가에 `0.5·Σ(log C - x)² + 1·Σ|Δ²x|`를 최소화하는 L1 필터(λ=1)를 적용한다. 하루 기울기 `< -0.000001`은 하락, `> +0.000001`은 상승, 그 사이는 횡보다. 같은 방향을 묶고 최소 길이 기본값은 10봉이다. 횡보에는 선을 긋지 않는다. 주·월봉의 단위·완료 판정은 M06-Q08을 먼저 닫는다.
3. 구간별 L1 추세를 가격축의 직선으로 근사한다. 상승선은 구간의 모든 저가 이하이고 최소 한 저가에 닿도록, 하락선은 모든 고가 이상이고 최소 한 고가에 닿도록 평행 이동한다. 직선 근사의 정확한 산식은 M06-Q09를 먼저 닫는다.
4. 화면 오른쪽 끝이 최신 완료봉인 마지막 구간만 `진행 중` 점선, 나머지는 실선이다. 저장·작도 채택·돌파/이탈 신호·감시·알림 연결은 없다.
5. C3에 별도 “자동 L1 추세선” 묶음을 추가한다. 구간 시작·끝 날짜, 방향, 직선 좌표, 진행 상태와 **계산에 쓴 화면 구간 시작·끝·시간틀**을 반환한다. 사용자의 최신·채택 작도 묶음과 revision을 혼합하지 않는다.
6. 구간 생략 시 대시보드 기본과 일치시킨다. 현행 기본은 일봉 최근 6개월이며 주·월봉으로 바꿀 때는 전체 구간이다(`stock-chart.js:6`·`:29`·`:41`, `chart-workspace.js:207`). 표시용 미래 여백은 계산에서 제외한다. 화면 복원용 `context.visible_range`를 세션의 기본값으로 몰래 읽거나 저장하지 않는다.

**풀이 방식(§8.1이 M06에 위임한 구현 선택):** 보관된 primal-dual 구현을 `drawings/l1_trendlines.py`로 이식한다. 새 최적화 라이브러리 도입 없이 기존 NumPy 범위에서 사용한다. 조 3 전에 Claude가 보관소 `invest-trend-research-archive`, 커밋 `120dd46`의 구현·관련 합성 기준값을 출처·파일 해시와 함께 인계해야 한다. 현재 원본을 읽지 않았으므로 이식 가능·수치 일치는 미검증이다. 다른 의존성이 필요하면 임의 설치·대체하지 말고 영향과 함께 새 질문으로 올린다. 인계 전 자동선 구현 완료를 선언하지 않는다.

### 4. 단계별 구현 순서

1. **선행 입력:** M00 실행기, M03 읽기 함수, M05 채택 근거 reader를 받는다. Claude의 L1 원본·출처·해시 인계를 확인한다. M06-Q07~Q09가 영향을 주는 옛 코드 처리·주월 계산·직선 산식은 결정 전 임의로 확정하지 않는다.
2. **부작용 없는 읽기:** 파일·테이블 존재 확인부터 읽기 전용으로 현재 공유 작도와 지정 revision을 읽는다. 없는 파일은 만들지 않고 옛 형식만 있으면 변환 필요 상태를 반환한다. `workspace_saved_at`과 payload는 같은 revision에서 읽는다.
3. **C3 계산:** M03의 최신 완료 일봉 종가·날짜를 결합하고 저장 시간틀(없으면 일봉)로 계산한다. 가격 기준·종목 불일치와 결측을 드러낸다. 최신·채택 목록을 분리하고 위 거리 공식과 같은 값으로 문장을 만든다.
4. **L1 계산:** 인계 원본의 목적함수·수렴 조건을 합성 기준값과 대조한 뒤 이식한다. 결정된 시간축·직선 산식으로 방향 묶음·10봉 최소·고저가 경계 이동·진행 중 표시를 구현한다. 미래 봉·0 이하 종가·실패 결과를 유효한 자동선으로 표시하지 않는다.
5. **화면 조각과 인계:** 이동 종료 후 계산, 화면 구간·시간틀 표시, 최신 응답만 적용하는 조각을 만든다. M10에 읽기 전용 API 서비스와 화면 조각을, M09에 `investment_drawings` 입력·세 묶음·상태 예시를 넘긴다. M05·M07에는 최신/채택 작도 읽기만 제공하고 자동선을 감시 입력으로 연결하지 않는다.
6. **격리 검사:** `tests/suites/M06.txt`에 아래 항목을 등록해 M00 실행기로만 실행한다. 조 4 연결·운영 적용 성공을 미리 주장하지 않는다.
