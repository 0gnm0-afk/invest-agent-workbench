## 1. 개편 뒤 모습 한 장

```
            [사용자]
     ┌─────────┴──────────┐
 Claude 세션             워크벤치 대시보드(브라우저)
 (대화·조사·논의)         종목 검색 → 차트 → 작도 / 재무 탭 / 감시·가격 위험
     │  MCP                     │  HTTP(loopback)
     ▼                          ▼
 ┌──────────── 서비스 층 (scripts/) ─────────────┐
 │ 지식   분석·논의·계획   작도 해석(신규)        │
 │ 가격 저장소   재무(출처 교체 층)   계좌 관측   │
 │ 기술 신호·시나리오·트레일링 → Telegram 전송   │
 └───────────────────────────────────────────────┘
     ▼ SQLite
 records · chart-workspaces · ohlcv · accounts · trailing-warnings · delivery
     ▲
 세션 없이 도는 것: 일봉 수집(Toss) → 신호 판정 → Telegram  (6단계에서 켬)
```

- 대시보드의 중심은 **차트 작도**이고, 작도는 세션에서 Claude가 읽을 수 있는 글 형태로 다시 불러온다(신규 계약 C3).
- 계좌 현황은 세션에서 MCP로 조회하고 필요하면 Claude 쪽 대시보드로 본다(§6 Q1·§8.1). 앱의 자동 계좌 조회는 없앤다.
- 종목 조사는 조사 스킬(얇은 절차) + deep-research. 결과는 지식 DB에 저장.

## 8. 모듈 문서 열린 질문에 대한 설계 결정 (2026-11-17)

Codex 모듈 문서 초안 14개의 열린 질문 55개를 묶어 정했다. 아래가 §3 계약·§4 순서보다 우선한다. 각 모듈 문서는 이 절을 반영해 고친다.

### 8.1 사용자 결정
- **자동 추세선 = L1 추세 필터 기반 (사용자 11/17, 원문 지식 DB `kn_52fc2aa001c2…`).** 매매 신호가 아니라 과거 구간의 상승·하락을 보는 참고선이다. 지금 운영 중인 `trendln` 자동선(`screening/trendlines.py`, `vendor/trendln`)과 나머지 추세선 로직(`src/invest_agent/trading/trendlines.py`, 테이버·스페란데오·하락 접근 등)은 모두 M01이 종료한다. 새 자동선은 M06이 만든다(`drawings/l1_trendlines.py`):
  1. 입력: **차트 화면에 지금 보이는 완료봉 구간**(사용자 11/17). 차트를 옮기거나 확대·축소하면 보이는 구간으로 다시 계산해 다시 긋는다(화면 이동이 멈춘 뒤 한 번, 짧은 지연). 시간틀은 화면의 시간틀(일·주·월)을 따른다. 그 구간의 로그 종가에 L1 추세 필터(Kim·Koh·Boyd·Gorinevsky 2009)를 적용한다. 목적함수와 값은 10/21 연구와 같게 `0.5·Σ(log C − x)² + 1·Σ|Δ²x|`(λ=1). 계산은 저장 일봉만 쓰는 읽기 전용 API(구간 시작·끝·시간틀 인자)로 하고 결과를 저장하지 않는다.
  2. 구간 판정: L1 결과의 하루 기울기가 `< −0.000001`이면 하락, `> +0.000001`이면 상승, 그 사이는 횡보. 같은 방향이 이어지는 구간을 하나로 묶는다. 횡보 구간에는 선을 긋지 않는다. 최소 구간 길이는 연구의 최단 구분(10봉)을 기본값으로 둔다.
  3. 선 긋기: 구간마다 L1 추세를 차트 가격축 위의 일차함수(직선)로 근사해 기울기를 정하고, **상승 구간은 그 기울기로 봉의 저가 아래쪽에 닿게(구간 안의 어떤 저가도 선 아래로 내려가지 않게), 하락 구간은 봉의 고가 위쪽에 닿게(어떤 고가도 선 위로 넘지 않게)** 평행 이동한다.
  4. 선은 보이는 구간에 따라 달라지는 참고선이다. 화면 오른쪽 끝이 최신 완료봉이면 마지막 구간은 새 봉이 들어오면 바뀌므로 "진행 중" 점선, 나머지는 실선으로 그린다. 돌파·이탈 신호나 감시·알림에는 연결하지 않는다.
  5. 세션: `investment_drawings`(C3)는 사용자 작도와 따로 "자동 L1 추세선" 묶음으로 구간 시작·끝 날짜, 방향, 직선 좌표와 **계산에 쓴 화면 구간(시작·끝·시간틀)**을 돌려준다. 세션에서 구간을 인자로 줄 수 있고, 주지 않으면 대시보드 기본 화면 구간을 쓴다.
